# Contributing

Contributions should improve the guide without exposing private camera or home-network information.

Before opening a pull request:

1. Replace all real addresses with documentation-only examples such as `192.0.2.50`.
2. Replace credentials with placeholders; `admin` may be documented as the username, but never include a password.
3. Remove MQTT configuration, unrelated cameras, personal hostnames, screenshots, and identifying logs.
4. Label results as verified, partially tested, or unverified.
5. Test Markdown and YAML syntax locally.

Please describe the camera model, firmware, stream dimensions, crop geometry, and whether detection and recording were tested. Do not claim full-resolution recording works unless playback and reconnect behavior have been checked.
